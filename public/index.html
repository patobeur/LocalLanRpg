Comment Jouer ?

1. Choisissez votre Héros

Sélectionnez le champion qui correspond à votre style de jeu : Tank, DPS, Support, ou Assassin.

2. Progressez sur les Lanes

Avancez avec vos sbires, détruisez les tours ennemies et gagnez de l'expérience pour débloquer vos compétences ultimes.

3. Détruisez le Nexus

L'objectif final est de détruire la base ennemie. Coordonnez l'assaut final pour remporter la victoire !

Développement Indépendant

LittleMoba est un projet passionné, développé de manière 100% indépendante. Loin des grosses productions, ce jeu est le fruit d'un amour pour les jeux vidéos et le développement web.

Chaque mise jour, chaque champion et chaque ligne de code est conçu pour offrir une expérience fun et accessible. Merci de faire partie de l'aventure !
